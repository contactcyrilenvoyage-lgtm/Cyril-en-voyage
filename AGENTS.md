# Cyril en Voyage

## Architecture du site

- Consulte la section [Architecture du site](README.md#architecture-du-site) avant de modifier les pages ou la navigation.
- Les pages Voyages et Aventures listent les fiches. Chaque fiche ouvre sa propre page de détail.
- Place le récit, les motivations et les liens vers les publications dans la fiche correspondante. La page Projet en cours a son propre bloc YouTube et Instagram.
- Quand tu ajoutes une fiche, mets à jour le carnet correspondant et les liens depuis l’accueil si la fiche y figure.
- Sur « Qui suis-je ? », garde le récit en une seule colonne large avec des paragraphes bien espacés. Regroupe les illustrations en petites vignettes sous le récit.

## Documentation

- Mets à jour le README dans le même changement quand tu modifies l’architecture, la navigation, le lancement en local ou la publication du site.
- Mets à jour ce fichier quand une consigne durable pour les agents évolue.
